
  # AI Lab Insight Workbench Demo

  This is a standalone GitHub Pages-ready demo for the AI Lab insight workbench UI.

  ## Running the code

  Run `pnpm install` to install the dependencies.

  Run `pnpm dev` to start the development server.

  Run `pnpm build` to generate the static site.

  Run `pnpm deploy` to publish the `dist/` directory to the repository's `gh-pages` branch.
